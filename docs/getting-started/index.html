新手路线:从安装到稳定使用

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

第一次接触 Leyra 的朋友,常见的困惑是「东西不少,不知道先看哪篇」。这篇把整个过程排成一条路线,照着顺序走,大概半小时就能把电脑配好。已经在用的老用户,可以直接跳到自己卡住的那一步。

先说清楚我们在解决什么问题

我们的出发点很简单:让 Claude、ChatGPT、Gemini 看到的网络出口固定下来,并且和你实际所在的国家一致。

很多人用 AI 时遇到的验证、受限、登录异常,背后常常是网络环境一直在变:今天走这个节点,明天走那个节点,同一个出口还被很多陌生人共用。Leyra 给你一个独享 · 静态 ISP 代理 IP(或者帮你管理你自己的独享 · 静态 ISP 代理 IP),再把 AI 流量稳定地送到这个 IP 上,其他流量照旧。

需要先说明的是,我们能做的是减少因网络环境变化被风控的情况,不能承诺账号一定不受限制。各家 AI 服务的账号和地区政策由它们自己决定。

第一步:花几分钟了解三个要素

动手之前,建议先读 稳定使用 AI 的三个要素。它讲网络、设备、使用习惯三件事各自起什么作用。理解了这些,后面每一步为什么这样设置,心里会更有数,也不容易被网上各种说法带偏。

第二步:安装插件,注册登录

Leyra 的操作基本都在浏览器插件里完成。

  1. 用官网提供的安装链接,在 Chrome 里安装「Leyra」插件。
  2. 点浏览器工具栏上的插件图标打开它。第一页是功能介绍,点「开通会员」或「已有账号,登录」。
  3. 可以用 Google 账号登录,也可以用邮箱注册。邮箱注册后要去邮箱里点验证链接,再回插件点「我已完成验证」。

详细的界面说明见 插件配置指南。

第三步:选套餐并开通

插件里有两种会员,可以在「两种会员有什么不同」里对比:

  • 独享 IP:我们给你分配一个只给你用的独享 · 静态 ISP 代理 IP,可以选地区(以插件里显示的库存为准)。
  • 自带 IP:你已经有自己的独享 · 静态 ISP 代理 IP,只需要填进连接信息,分流、监控、体检这些由我们负责。

付款后,独享 IP 一般不到一分钟就分配好;自带 IP 则会让你填写 IP 的连接信息。如果拿不准该选哪种,可以先读 什么是独享 · 静态 ISP 代理 IP。

第四步:把配置装到你的设备上

开通完成后,插件会进入「获取配置」页,让你选择客户端。

  • 电脑(Windows、macOS):用 Clash Verge Rev。在插件里复制一段扩展脚本,粘贴到 Clash Verge Rev 就行。步骤见 电脑端:Clash Verge Rev 配置指南。
  • iPhone、iPad:用 Shadowrocket(小火箭)。在插件里扫码或复制链接导入。步骤见 iPhone:Shadowrocket 配置指南。

电脑端的脚本会让 AI 流量经过你订阅里的节点再连到独享 IP,所以电脑上需要先有一份能正常使用的订阅。前置节点怎么挑,见 前置节点怎么选。

目前暂不支持安卓、软路由和独立客户端,后面支持了会另外写教程。

第五步:做一次网络环境体检

电脑上的 Clash Verge Rev 连上以后,插件会自动进入首页并检测一次。首页顶部有一句结论,下面是你的 IP 和「网络环境体检」入口。

体检会告诉你:AI 网站看到的出口 IP 和国家、DNS 和 WebRTC 是否一致、AI 网站 / 其他境外网站 / 国内网站分别走的是哪个出口。全部正常再去用 AI。如果有问题,处理办法就写在对应项目下面。想自己再核对一遍,可以看 怎样确认 AI 用的是你的独享 IP。

之后浏览器开着时插件会定时复检。打开 AI 网站前如果发现出口不对,插件会先拦住,告诉你 AI 网站看到的是哪个 IP、该怎么修,避免在错误的网络下登录。

第六步:再处理账号和付费

网络确认没问题之后,再去做跟账号有关的事:

  • 还没有 AI 账号:先读 注册 AI 账号的注意事项。
  • 打算订阅付费版:先读 订阅付费的注意事项。
  • 已有老账号:刚换到新的网络环境时,先正常使用一段时间,别急着改资料或换付款方式。

日常使用

配置好以后,平时基本不用管。规则会自动更新,IP 如果需要更换,Clash 端也会自动拿到新的,不用重新复制脚本。遇到问题可以按这个顺序找答案:

  • 网络连不上、速度慢:网络常见问题
  • 网上说某家 AI「大面积受限」:看到传闻时怎么自查
  • 担心这担心那:别被焦虑带着走
  • 账号真的出了状况:账号被停用或受限后怎么办

还是解决不了,在插件里打开诊断报告,一键复制后发给在线客服,我们会帮你看。
