哪些流量能管住,哪些管不住

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

这篇说明在虚拟网卡模式下,哪些程序的 AI 流量会自动走你的独享 · 静态 ISP 代理 IP,以及哪些情况客户端管不住,需要你自己注意。本地代理模式的情况见文末。

能管住的

浏览器

Chrome、Edge、Firefox 等所有浏览器访问 Claude、ChatGPT、Gemini,都会从独享 · 静态 ISP 代理 IP 出去。即使浏览器开了「安全 DNS」,客户端也能认出访问的是哪个网站,照样走独享 · 静态 ISP 代理 IP。

AI 桌面 App

Claude、ChatGPT 的 Windows 桌面 App 同样会被接管,不需要额外设置。

Claude Code 等命令行和编程工具

Claude Code、Codex 等命令行工具,以及 Cursor 等编程工具,流量都会经过虚拟网卡,不管它们有没有设置代理。

如果你以前给这些工具设过 Clash 的代理端口(比如 127.0.0.1:7890 或 7897),也不用改:这些端口现在由 Leyra 接管,流量照样走独享 · 静态 ISP 代理 IP。

管不住的,请注意

浏览器里的代理插件

SwitchyOmega 这类插件如果指向另一台代理服务器,浏览器的流量会先到那台服务器,AI 网站看到的就是那台服务器的 IP,而不是你的独享 · 静态 ISP 代理 IP。

使用 AI 时,请把代理插件切换到「直接连接」或「系统代理」。如果插件指向的是本机的 Clash 端口(7890、7897),则不受影响。

浏览器自带的 VPN

Opera 自带的 VPN、Edge 的「安全网络」等功能,也会让流量绕开独享 · 静态 ISP 代理 IP。使用 AI 时请关掉。

其他 VPN 软件

其他 VPN 软件和 Leyra 同时开着时,流量可能被它们截走。使用 AI 时请只开 Leyra。

怎么确认 Claude 看到的是你的独享 · 静态 ISP 代理 IP

首页底部的「Claude 看到的 IP」这一项,会直接去问 Claude 看到的是哪个 IP,并和你的独享 · 静态 ISP 代理 IP 核对。ChatGPT、Gemini 同样走独享 · 静态 ISP 代理 IP,但客户端不单独检测它们。

需要注意的是,这一项是客户端自己去问的,看不到你浏览器里装了什么插件。如果你装了代理插件,建议在浏览器里打开 claude.ai/cdn-cgi/trace,看 ip= 后面的地址和「网络」页显示的独享 · 静态 ISP 代理 IP 是否一致(网络页的 IP 部分遮罩,对比露出的几段即可)。

本地代理模式下

开着 Clash 等代理软件、客户端处于本地代理模式时:

  • 浏览器:会跟着系统代理走,系统代理通常是 Clash 设置的,所以浏览器走的是 Clash。首页会提示「浏览器的出口不是独享 IP」。
  • Claude Code:它只认自己的代理设置。首页「Claude Code 线路」这一项会检查它的设置,不对时可以点「一键修正」,把它指到 Leyra 的端口,随时可以撤销。
  • 其他命令行工具:需要自己把代理设置为 Leyra 的端口。

最简单的做法是退出 Clash,使用虚拟网卡模式,见《虚拟网卡模式和本地代理模式》。
