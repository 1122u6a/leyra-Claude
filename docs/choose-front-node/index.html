前置节点怎么选

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

用 Leyra 时,AI 流量不是直接连到你的独享 IP,而是先经过你自己订阅里的一个节点,再到独享 IP。中间这个节点,我们叫它「前置节点」。很多「突然连不上」「打开很慢」的问题,最后都查到前置节点身上。这篇讲它是什么、在哪里设置、怎么挑。

前置节点在整条路上的位置

一次 AI 请求的路线是这样的:

  1. 你的电脑或手机
  2. 前置节点(你自己订阅里的某个节点)
  3. 你的独享 IP
  4. AI 网站

有两点要先说清楚:

  • 前置节点不改变出口。不管前置换成哪个节点,AI 网站看到的始终是你的独享 IP。所以换前置节点是安全的,不用担心「换节点等于换了出口」。
  • 前置节点决定这条路好不好走。前置节点慢,AI 就慢;前置节点断了,整条路就断了,即使独享 IP 本身完全正常。

在哪里设置

电脑:Clash Verge Rev

扩展脚本会在 Clash Verge Rev 的「代理」页加几个分组,和前置有关的是两个:

  • 普通代理:你在这里选中的节点,就是首选的前置节点。同时,其他境外网站也走这个分组,所以它也影响你平时上网。
  • AI 前置:由脚本自动管理,不需要你手动选。它排在第一位的是你在「普通代理」里选的节点;这个节点不可用时,它会自动换到订阅里其他能用的节点,等你选的节点恢复后再换回来。

也就是说,你只需要在「普通代理」里选一个好用的节点,剩下的由「AI 前置」兜底。

iPhone:Shadowrocket

导入配置后,小火箭里有一个「前置中转」分组,默认是「自动选择」,会从你小火箭里已有的节点中挑一个延迟低的。想自己指定,就把「前置中转」改成「手动选择」,再到「手动选择」里挑一个节点。

怎么挑一个好的前置节点

稳定比快更重要

AI 对话时连接要保持比较久,特别是生成长回答、上传文件的时候。一个延迟稍高但很少断的节点,往往比一个测速很快但时不时掉线的节点好用。如果你发现插件体检里的连通率偏低,或者用着用着经常要重新加载,先考虑换一个更稳的前置节点。

延迟别太高

前置节点加上独享 IP,整条路比你平时上网多一段,延迟会叠加。前置节点本身延迟就很高的话,每次发消息都要多等一会儿。一般来说,前置节点离独享 IP 所在的地区近一些,整体延迟会低一些,但这取决于你的节点服务商的线路,最好实际试几个对比一下。

留意基于 UDP 的节点

有些节点用的是基于 UDP 的协议(比如 Hysteria2、TUIC 之类)。在一些网络环境下,运营商会限制 UDP 流量,这时这类节点可能会一起断掉,而基于 TCP 的节点照常能用。如果你发现某一类节点经常集体掉线,可以把首选的前置节点换成基于 TCP 的。电脑上的「AI 前置」在自动换备用节点时,也会优先选基于 TCP 的节点。

节点本身要正常

订阅里常有一些不是真正节点的条目,比如写着剩余流量、到期时间、官网地址的。这些是连不通的,不要选它们做前置。

连不上时怎么判断是不是前置的问题

下面这些情况,大概率和前置节点有关:

  • 其他境外网站都正常,只有 Claude、ChatGPT 打不开。
  • 插件提示 IP 不可用,但你刚刚换过节点订阅,或者订阅里的节点最近不太稳。
  • iPhone 上手机自检显示「连不上你的 IP」。

排查步骤:

  1. 换一个前置节点。电脑上在 Clash 的「普通代理」里换一个节点;iPhone 上把「前置中转」改成「手动选择」,换一个节点。
  2. 回插件重新检测。电脑上在体检页或首页点「重新检测」;iPhone 上重新扫码自检。
  3. 多试几个。如果换了好几个节点都不行,再看是不是别的问题,比如 Clash Verge Rev 没在运行、扩展脚本没启用。可以对照 网络常见问题 排查。

还有一种可能,只是我们推测、没法替你确认:个别节点服务商会限制转发到某些端口,导致这家的节点连不上独享 IP,而连其他网站一切正常。如果你订阅里所有节点都连不上独享 IP,换另一家的节点却可以,可以问问原来的服务商是否有这类限制。

都排查过还是不行,在插件的体检页复制诊断报告,发给在线客服,我们一起看。

换了节点订阅以后

不需要重新复制脚本,也不需要重新导入小火箭配置。

  • 电脑上,扩展脚本每次运行都会把订阅里的节点重新收进「普通代理」和「AI 前置」。更新订阅后,新节点会自动出现在里面,你在「普通代理」里重新选一个就行。
  • iPhone 上,「自动选择」和「手动选择」是从小火箭里现有的节点里挑的,换了订阅只要小火箭里有新节点就行。

前置节点不需要和独享 IP 一样「干净」

AI 网站看不到你的前置节点,它只看到最后的独享 IP。所以挑前置节点时,不用在意它是不是多人共用、出口在哪个国家,只看两件事:能不能稳定连上你的独享 IP,速度够不够快。
