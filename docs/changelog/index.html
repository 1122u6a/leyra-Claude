更新日志

桌面客户端每个版本改进了什么。客户端会自动更新，也可以点左下角版本号旁的图标手动检查。

v1.0.02026-11-15

  • 界面全部重做，你的登录、独享 IP、节点和设置都保留，不用重新填
  • 更稳：换服务商、换地区、改分流、自动更新、开机时，Claude 都只走你的独享 IP
  • 连接有问题时 Claude 先拦着，首页写明原因，要不要放开由你决定
  • 更好懂：首页一眼看状态，有问题会告诉你是哪里、该点哪个按钮；第一次使用有新手三步
  • 节点页改版，能看到到独享 IP 的延迟；侧栏显示会员和到期日，可以设置昵称和头像；窗口更大，可以调字号
  • 客服在客户端里直接聊，可以发截图和检测报告；新增通知公告和更新日志
  • 终身 VIP：一次付款，最多 5 台设备（电脑和手机都算），已开通的用户自动从 3 台升到 5 台

v0.1.402026-11-12

  • 修复部分云电脑连接后断网的问题

v0.1.392026-11-12

  • 云电脑上的一项检测改为只提醒，不影响使用

v0.1.382026-11-12

  • 修复部分云电脑连接后 Claude 一直被拦的问题
  • 独享 IP 暂时不通时，国内应用照常上网
  • 连接异常时，电脑上网恢复更可靠
  • 客服窗口可以一键发送检测报告，也能存成文件

v0.1.372026-11-11

  • 换服务商、换地区、改分流时更稳，Claude 始终走你的独享 IP
  • 切换后连不上时首页写明原因
  • 和其他代理软件冲突时会提醒你

v0.1.362026-11-11

  • 断开后网络恢复更可靠，换 Wi-Fi 也正常
  • 减少检测误报
  • 更多 Claude 相关页面走你的独享 IP

v0.1.352026-11-10

  • 修复部分独享 IP 一直显示「出口未确认」的问题
  • 检测报告更完整，客服排查更快

v0.1.332026-11-05

  • 别的软件反复改网卡 DNS 时，Claude 不再一会儿能用一会儿被拦：客户端自动改回并给黄色提醒，能认出来的会写明可能是哪个软件；真的查到泄露才拦截
  • 订阅拉不到时说清原因（比如返回 504、链接打开不是节点列表），也会经电脑上开着的代理工具再拉一次；服务商的提示条目不再被当成节点
  • Claude Code 检测更准：客户端没连接时直接告诉你，连上后自动恢复；本地端口出问题时会自动重新打开
  • 用自己的工具时更省心：选中的 v2rayN 不再被报成代理冲突，诊断写明经哪个工具连接；工具里已经接了独享 IP 时会提醒你去掉重复的一段
  • 客服聊天可以发表情和文件，输入区和微信一样；图片偶尔加载失败会自动重试
  • 没有管理员权限时可以一键以管理员身份重启；连接列表把客户端自己的检测标成「自检」，不再混在 AI 网站里

v0.1.312026-11-04

  • 客服聊天窗口改成微信样式：客服回复时响提示音并自动弹出；可以引用消息，图片点一下放大；显示已读和未读
  • 检测报告不再自动带上，要发时点「附上检测报告」，或在「网络」页点「发给客服」
  • 节点断线时说清楚是哪一段连不上，恢复后几秒内变回正常；减少 DNS 防泄露的误报和误拦
  • 用自己的工具时，诊断不再误报「订阅里没有节点」；订阅可以关掉自动更新，只在点「刷新订阅」时才拉，拉不到继续用上次的节点

v0.1.302026-11-04

  • 客服窗口改成右下角的聊天窗：打开就是对话，回车就发，可以贴截图，不用留邮箱；第一条消息会自动附上检测报告（已隐藏订阅和密码）

v0.1.292026-11-04

  • 新增在线客服：点「联系客服」直接发消息，可以贴截图、附上检测报告（已脱敏），客服回复有红点和通知；没登录也能用。微信客服已停用
  • 独享 IP 偶尔超时不再拦很久：发现没测通马上重测，通了立刻恢复；复查时首页显示「正在复查线路」，首页和底部的检测状态也保持一致
  • Google 登录改成和其他 Google 网站走同一条线，减少 Google 要求验证的情况
  • DNS 防泄露也接管网卡上的 IPv6 DNS，修复部分加速器软件造成的 DNS 泄露提示

v0.1.282026-11-03

  • 首次设置更稳：电脑上开着 Clash Verge 才默认推荐「用它」，否则默认导入订阅，「用我自己的工具」仍然可以选
  • 出口核对更准：重新连接后不会再把上一次连接的检测结果套到新连接上；出口不对时会写明是哪种情况，方便排查
  • 首页和底部的检测状态保持一致：被「Claude 看到的 IP」拦住时，底部那一项也显示异常
  • 用自己的工具时连接更快，不再多等订阅

v0.1.272026-11-02

  • 修复「用我自己的工具」时，你工具里的 REALITY 节点会连不上（握手失败）的问题
  • 「用我自己的工具」：自动选的工具连不通独享 IP 时，会换电脑上另一个工具再试；你的工具一直把系统代理改回去时，客户端会提示你去关掉它的「系统代理」，不再互相抢；选中的工具不再被报成「代理冲突」
  • 修复游戏加速器、VPN 等虚拟网卡上的 DNS 让「DNS 防泄露」一直报泄露的问题；报泄露时会写明是哪块网卡
  • 修复「断网保护」在流量其实走着虚拟网卡时误报异常的问题，异常时会写明路由的跃点数和怎么改

v0.1.262026-11-02

  • 不用再复制订阅了：节点可以直接用你电脑上开着的 Clash Verge、v2rayN 等，客户端自动找到它的端口，点「用它」就行；导入订阅照旧保留（节点页可以切换）
  • 你的工具没在运行时，首页会直接告诉你「Claude 已拦截」，打开它就自动恢复；它换了端口也会自动跟上
  • 修复国内部分网络「DNS 防泄露」一直检测不出来、Claude 一直被拦的问题
  • 修复自带 IP 的用户「还不知道独享 IP 所在国家」一直过不了 DNS 检测的问题
  • 本地代理模式下客户端会接管系统代理，浏览器不再绕过客户端走别的代理软件
  • 修复「添加手机 → 安卓 → 生成安卓配置」报错的问题
  • 自动更新安装的那几十秒里会先拦住 Claude，不让它走别的线路

v0.1.252026-11-01

  • 接管方式可以选了：默认「虚拟网卡」管整台电脑；有软件和虚拟网卡冲突时，可以在软件设置里改成「系统代理」，断开时自动恢复原来的代理设置
  • 没有管理员权限时，客户端会自动把系统代理设好，浏览器直接就能走独享 IP

v0.1.242026-10-31

  • 以后的新版会在你没用 Claude 的时候自动装好并重新连上，不用自己点安装
  • 修复部分节点在这里大面积超时的问题；检测服务直连不通时会自动换路
  • 填独享 IP 更省心：整行粘贴自动拆开，认出常见供应商的格式直接给填法，协议选错自动帮你改，连不上时说清是协议、账号还是白名单的问题
  • 节点可以加星置顶、按延迟或名称排序；「分流测试」改名「分流规则」，加了 Grok 和 Meta AI，自己加的规则和内置规则重复时会提示

v0.1.232026-10-30

  • 分流可以自己设了：Claude 固定走独享 IP，ChatGPT、Gemini、Grok、Meta AI 可以选走独享 IP 还是你的节点，还能自己加网站规则
  • 节点可以按地区自动选最快，比如只在日本节点里挑延迟最低的
  • 新增「产品共创」：想要什么功能直接提、给别人的需求投票，还能贴截图；客服和共创放在右下角，可以拖动、可以关闭
  • 重新登录不用再选设备；分流测试打开就自动测；账号页可以注销账号

v0.1.222026-10-30

  • 新增「连接」页：每条连接走哪条线一目了然，首页也会告诉你过去 1 小时 Claude 的连接是不是全部走独享 IP
  • 新增「分流测试」：一键测 AI 网站、国外网站、国内网站三条线是不是都走对了
  • 独享 IP 连不上时直接告诉你原因和怎么办，比如「这家节点服务商不肯转发到你的独享 IP」
  • 新添加的节点服务商会自动试一次，连不通就换回原来那家；常见的 IP 检测网站也会显示你的独享 IP
  • 首页的提示可以手动关掉；修复装了 Radmin VPN 等组网软件时被误判为其他 VPN、检测一直不通过的问题

v0.1.212026-10-29

  • 浏览器开了「安全 DNS」时，DNS 查询也走你的独享 IP，官网检测和客户端的结果一致了

v0.1.202026-10-29

  • 新用户可以免费试用 1 天，首页显示剩余时间，快到期时会提醒
  • 新增终身 VIP：一次付款永久使用，电脑和手机都能用
  • 检测结果的「一键修复」会直接带你去该去的页面
  • 节点连不上独享 IP 时，换个节点就能自动恢复

v0.1.152026-10-28

  • 新版本下载好后，首页会提示你，点一下重启就能安装
