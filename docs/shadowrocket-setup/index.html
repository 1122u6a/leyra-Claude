iPhone:Shadowrocket 配置指南

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-14

这篇讲怎么在 iPhone(或 iPad)上用 Shadowrocket,也就是大家常说的「小火箭」,接入 Leyra。配好以后,手机上访问 Claude、ChatGPT、Gemini 的流量会走你的独享 IP,和电脑用的是同一个 IP;其他网站照旧走你原来的节点。

整个过程分三段:在插件里生成配置,在小火箭里导入并启用,最后用手机自检确认 AI 流量真的走了你的 IP。

开始之前

  • 一台装好 Shadowrocket 的 iPhone 或 iPad。
  • 小火箭里已经有你自己能用的节点(你原本的订阅)。这一点很重要:我们的配置不带普通节点,连接你的独享 IP 时要先经过你自己的某个节点转发,这一段叫「前置」。小火箭里一个节点都没有,配置导进去也连不上。
  • 电脑上已经装好 Leyra 插件,并且已经开通会员、分配好了 IP。还没装插件的话,先看 插件配置指南。

第一步:在插件里生成小火箭配置

第一次配置时,插件会带你走到「获取配置」这一步,在「选择你的客户端」里找到 Shadowrocket(下面写着 iPhone · iPad · Conf 配置),点它右边的 获取配置。

如果电脑已经配好了 Clash Verge Rev,现在想再加一部手机:在插件首页点「我的 IP」那张卡进入 IP 详情,点「设备」,再点 添加设备,然后同样选 Shadowrocket。

生成后插件会显示一个二维码和「复制配置链接」按钮。这个链接相当于这部手机的专属钥匙,里面包含连接你独享 IP 的信息,不要发给别人,也不要截图发到群里。

第二步:在小火箭里导入配置

有两种导入方式,任选一种。

扫码导入(推荐)

  1. 打开小火箭,点首页右上角的扫码图标。
  2. 对准电脑屏幕上插件显示的二维码扫一下。

注意要用小火箭自己的扫码功能。iPhone 自带的相机扫这个码没有用。

复制链接导入

如果扫不了,在插件里点 复制配置链接,想办法把链接发到手机上(比如发给自己的备忘录),然后在小火箭底部切到「配置」页,点右上角的「+」,粘贴链接下载。

第三步:启用这份配置

  1. 在小火箭的「配置」页,点刚导入的这份配置,选 使用配置。
  2. 回到首页,把「全局路由」选成 配置。
  3. 打开顶部的连接开关。第一次打开时 iOS 会询问是否允许添加 VPN 配置,按提示允许即可。

「全局路由」这一步最容易漏。如果选的是「代理」,所有流量都会走首页选中的那一个节点,分流就不起作用了。

小火箭下载配置后,电脑上的插件会自动发现,页面会继续往下走,不用你手动刷新。如果迟迟没有反应,可以点插件里的「我已导入,立即刷新」。

第四步:手机自检

导入成功后,插件页面会出现「最后一步:在手机上自检」和一个新的二维码。这次要用 iPhone 自带的相机 扫,在 Safari 里打开自检页。自检页会检查手机上 AI 流量的出口,结果会同步回插件:

  • 显示「手机已验证:AI 流量走的是你的 IP」,就说明配好了。
  • 显示「AI 流量没有走你的 IP」,先确认小火箭正在使用这份配置、「全局路由」选的是「配置」,再扫码自检一次。
  • 显示「连不上你的 IP」,多半是前置节点连不上你的 IP,处理方法见下面「claude.ai 打不开」那一条。

扫不了码的话,可以点「复制自检链接」,发到手机上用 Safari 打开。

插件里的网络环境体检只检测电脑上的浏览器,手机是否正常要靠这个自检来确认。

导入后小火箭里多出来的分组

导入以后,小火箭里会多几个分组。一般都不用动,了解一下各自管什么就行:

  • AI:Claude、ChatGPT、Gemini 以及它们的登录、人机验证、付款相关的域名,都固定走这个分组,里面只有你的独享 IP 这一个节点。
  • 前置中转:连接独享 IP 时先经过的节点。默认是「自动选择」。
  • 日常上网:除了 AI 和本地网站以外的其他境外流量走这里,默认也是「自动选择」,也可以改成手动选择或直连。
  • 自动选择:从你小火箭里已有的节点中自动挑一个延迟低的。
  • 手动选择:想自己指定节点时用。把「前置中转」或「日常上网」改成「手动选择」,再到「手动选择」里挑一个节点。

你所在地区的网站会直连,不走任何节点。所在地区是在插件里创建这份配置时按电脑设置自动识别的。

常见问题

给 AI-Network 开头的那个节点测速,显示超时?

小火箭默认的测速方式对这个节点不准,显示超时不代表不能用。到小火箭的设置里,把连通性测试的方式改成 TCP,再测就有数字了。真正判断能不能用,以手机自检和实际打开 AI 网站为准。

所有网站都打不开,或者所有网站都走了独享 IP?

检查首页「全局路由」是不是「配置」。

claude.ai 打不开,其他境外网站正常?

多半是「前置中转」当前用的节点连不上你的独享 IP。把「前置中转」改成「手动选择」,在「手动选择」里换一个节点再试,换好后重新扫码自检。怎么挑前置节点,可以看 前置节点怎么选。

换了 IP,或者在插件里重新生成了配置,手机要做什么?

小火箭的配置里直接写着连接信息,不会像电脑上的 Clash 脚本那样自己去拿新 IP。换 IP 后,在小火箭「配置」页下拉刷新,或者点这份配置选「更新」。如果是重新生成了配置链接,旧链接会立即失效,需要按上面的步骤重新导入一次。

换了自己的节点订阅,要重新导入吗?

不需要。「自动选择」和「手动选择」会从你小火箭里现有的节点中挑,换了订阅只要小火箭里有新节点就行。

配置链接不小心发出去了怎么办?

在插件里这部手机的配置页底部,点「配置链接泄漏了?重新生成这台设备的配置」。只有这部手机的旧链接会失效,其他设备不受影响。重新生成后在手机上重新导入。

支持安卓吗?

目前不支持安卓,手机端只支持 iPhone 和 iPad 上的 Shadowrocket。
