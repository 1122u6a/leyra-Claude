桌面客户端常见问题

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

开机后要不要手动点连接?

不用。在「软件设置」里打开「开机启动」和「启动后自动连接」,开机后客户端会自动在后台启动。

如果电脑开机时还没连上 Wi-Fi 或网线,首页会显示「正在等电脑连上网络」,网络好了以后会自动连接,最多等 5 分钟。

如果开机后客户端没有自动启动,多半是安全软件把开机启动关掉了,见《安全软件弹窗和拦截怎么办》。

首页提示「电脑还没有连上网络」

客户端检测到电脑现在连不上外网。请先确认 Wi-Fi 或网线已经连好,能打开国内网站,再点「连接」。

从 Wi-Fi 换成网线,或换了一个 Wi-Fi,要重新连接吗?

不用。客户端会自动接管新连上的网络,AI 流量继续走独享 · 静态 ISP 代理 IP。换网络的那几秒 AI 网站可能会短暂打不开,属于正常现象。

电脑睡眠唤醒后

客户端会在唤醒后自动重新检测防护,一般一分钟内恢复正常,不需要手动操作。

断开连接或退出客户端后,其他网站打不开

正常情况下,断开或退出时客户端会把网卡的 DNS 改回原来的设置。如果客户端是被强制结束的(比如在任务管理器里结束进程、电脑突然断电),DNS 可能没来得及改回去。

解决办法:重新打开一次 Leyra 客户端,它会自动恢复。如果已经卸载了客户端,请重新安装再卸载一次,或在 Windows 的「网络和 Internet」设置里,把网卡的 DNS 改回「自动」。

关机时会不会很慢?

不会。关机时客户端会立刻退出,不会拖慢关机。如果关机太快没来得及恢复 DNS,下次打开客户端时会自动处理。

和 Clash 能一起用吗?

能,但不推荐。开着 Clash 时客户端会改用本地代理模式,浏览器多半走的是 Clash,防护也会打折扣。用 AI 时建议完全退出 Clash,Leyra 会通过你的节点订阅照顾其他海外网站。详见《虚拟网卡模式和本地代理模式》。

一个账号能在几台电脑上用?

每个账号最多可以在 3 台设备上使用(电脑和手机小火箭都算),都使用同一个独享 · 静态 ISP 代理 IP。在「软件设置」的「设备管理」里可以看到每台设备最近一次使用的时间,不用的设备可以删除,删除后那台设备的配置失效,其他设备不受影响。

怎么卸载?

在 Windows 的「设置 → 应用」里找到 Leyra,点卸载。卸载时会弹一次管理员授权,用来恢复网卡的 DNS 和删除开机启动任务。卸载后电脑的网络设置会恢复成安装前的样子。

怎么更新到新版本?

打开了「自动检查更新」的话,有新版本会自动下载,下次重启客户端时安装。也可以点左下角版本号旁边的小图标手动检查。更新时如果安全软件弹窗,请选择允许。

还有问题怎么联系我们?

点客户端右上角的「菜单」→「在线客服」,扫码添加微信客服。如果是连接问题,请先在「网络」页点「网络诊断」并复制报告,一起发给客服,能更快找到原因。
