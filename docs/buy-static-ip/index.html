独享 · 静态 ISP 代理 IP 怎么买

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

先说清楚三件事

你要买的是独享 · 静态 ISP 代理 IP（SOCKS5 或 HTTP，带账号密码）。不是宽带的固定 IP，也不是云服务器，这两种都用不了。

  1. Leyra 不卖 IP。 工具只负责把你的 IP 固定住：AI 网站始终从这条 IP 出去，其他网站照旧走你自己的节点。IP 你自己向供应商买，一个月几十块。
  2. IP 的问题找供应商。 连不上、速度慢、到期续费、退款，都由卖给你的供应商处理。工具这边只管「有没有把流量送到这条 IP」。
  3. 独享 · 静态 ISP 代理 IP 是给已经能用的账号长期稳定用的，不是用来注册新号的。 注册新号，请用你自己家里的网络。也不要在这条 IP 上登录以前被封过的号，会连累这条 IP。

买之前，记住这四条

  • 选「静态」「独享」，不选「动态」「共享」。 动态 IP 每隔一会儿就换，共享 IP 很多人一起用，都正好和我们要的相反。
  • 选美国。 Claude 支持的地区里，美国线路最多、最便宜。
  • 先买一个月试。 用顺了再买三个月，通常有折扣。
  • 一个人一条。 一条 IP 最多给你自己的 3 台电脑用，不要和朋友合买。

推荐：kookeey

我们之前自己用的就是 kookeey，中文页面，支持支付宝，有中文客服。

  • 买哪种：静态 ISP（页面上的分类名可能会变，认准「静态」+「ISP」，不要选「动态」「流量包」）
  • 地区：美国
  • 价格：10 月初我们查到的是美国 1 个月约 ¥57，3 个月约 ¥154（打九折）。以官网当天价格为准
  • 付款：支付宝等，以官网付款页为准
  • 有效期：按月买，到期不自动续费，记得自己续

步骤：

  1. 打开 kookeey 官网，用邮箱或手机号注册账号
  2. 充值或直接下单，在产品里选「静态 ISP」，地区选美国，时长选 1 个月
  3. 付款后等几分钟，在后台的线路列表或订单详情里能看到这条 IP
  4. 记下这几样：协议、连接地址、端口、账号、密码、出口 IP（出口 IP 就是这条 IP 本身；连接地址有时是供应商的网关地址，和出口 IP 不一样，照着后台写的填）

注意：kookeey 新买的线路默认用的是整个账户通用的账号密码。如果你在 kookeey 买了不止一条，建议在线路设置里给这条单独改一组账号密码。

备选

下面两家我们没有自己长期用过，价格和付款方式请以官网为准：

  • IPRoyal：海外老牌，有静态 ISP 线路，美国可选，页面是英文
  • 亮数据（Bright Data，中文站 bright.cn）：有中文站，有「ISP 代理」即静态线路，个人买单条可能偏贵

选哪家都一样，只要满足：静态、独享、美国、能拿到协议、连接地址、端口、账号、密码和出口 IP。

买完怎么填进 Leyra

  1. 打开 Leyra，登录
  2. 进入「填写你的 IP」
  3. 把供应商给你的信息依次填进去：

- 协议：一般选 SOCKS5（供应商写的是 HTTP 就选 HTTP）
- 地址：供应商后台写的「连接地址」，可能是一串数字（比如 203.0.113.10），也可能是一个域名；不要带 http:// 和端口
- 端口：一个数字，比如 1080
- 账号
- 密码
- 出口 IP：这条 IP 本身，AI 网站应该看到的就是它

  1. 点「检测并继续」，客户端会先检测这条 IP 能不能连上、出口是不是它
  2. 等圆圈变绿就好了。之后不管你换哪个节点、连哪个 Wi-Fi，AI 网站都从这条 IP 出去

常见问题

连不上 / 检测不通过？
先在供应商后台确认线路状态是「正常」、没过期，账号密码没填错。还不行，把检测结果要点发给供应商客服。如果供应商说线路没问题，再来找我们看是不是你的节点挡了这条线路（有些节点服务商不允许转发到别的线路，换一个节点订阅就好）。

可以用这条 IP 注册新号吗？
不建议。新号注册请用你自己家里的网络，注册好、用顺了，再接上这条 IP 长期用。

以前被封过的号能在这条 IP 上登吗？
别登。会让这条 IP 也被 Claude 记住。

到期了怎么办？
去供应商那里续费。续的是同一条，地址不变，工具里不用改。换了新 IP 的话，回到「套餐」页点「修改你的 IP」，改成新的连接信息。

装了工具、买了 IP，账号就不会出问题了吗？
不是。账号出问题有三类原因：所在地区、违规或共享账号或代充、出口 IP 老变。我们只解决第三类。
