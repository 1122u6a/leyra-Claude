# Mac 1.1.8 界面与功能规格

这是 Windows 版要对照的产品规格。它描述 Mac 已发布的界面和行为，Windows 的系统接管能力由真机验收确认。

## 主窗口

- 左侧顶部是橙底白字的 Leyra 标识、软件名和账号入口。账号入口显示昵称与授权，如「终身 VIP」。
- 主导航依次为「首页」「节点」「分流规则」「诊断与记录」。通知公告和软件设置有独立入口，显示版本号与更新日志入口。另有客服入口。
- 主背景为浅暖色，内容用白色圆角卡片。主操作用橙色，停用和次要操作用低对比度样式。MiSans 用于中文界面，IP、端口、时间和字节数要清晰可扫读。使用 [橙底 Leyra 字标](../design/Leyra-icon.png)。
- 首页卡片、线路行及诊断表在窄窗口保持可操作，长列表可滚动。切换风险用文字和状态共同表达，颜色只用作辅助。

## 节点

- 主页面可选「节点订阅」或「用我自己的工具」。使用本机工具时显示工具名、地址、端口、状态，提供重新扫描及更换端口。
- 「VLESS 节点」打开管理面板。链接字段隐藏明文，支持导入 VLESS TCP + REALITY。导入后从新节点读取实际出口，核验成功便登记为备用。无需用户填写出口 IP。
- 已导入节点显示「Mac Claude 出口 IP」或待核验状态。提供「重新检测出口」。检测失败保留节点并显示原因。已登记 IP 漂移时保留原登记值，提示核实，不把新 IP 当作自动恢复目标。
- 选择节点时显示上传、下载与累计量。Mac 当前统计基于连接采样，可能漏掉短连接。iPhone 流量从对应客户端查看。
- iPhone 分流入口提供「生成 iPhone 二维码」和「保存分流文件」。已有前置节点时，扫码后可按提示到小火箭的「代理通过」确认前置节点并点「保存」。保留此流程和现有手机配置。

## 分流规则

- 显示内置受管域名，以及用户添加的域名和程序。普通网站、Codex 和未列入保护的程序保持原有网络路径。
- 域名与程序按各自维度校验并显示实际启用状态。Claude 浏览器请求以域名规则覆盖，桌面客户端和子进程也要实测。Mac 的 `.app` 文件选择应替换成 Windows 适配入口。
- 受管流量只走当前核验通过的出口。网络或组件异常时优先拦截，禁止落到直连或未经确认的备用 IP。

## 诊断与记录

| 标签页 | Mac 1.1.8 要点 |
| --- | --- |
| 诊断 | 「你的网络身份」显示登记和实测 IP、第一跳、到线路延迟、接管方式、连接时间；逐项状态旁提供「重新检测」「复制报告」「保存为 txt」 |
| 安全检查 | 汇总出口、DNS、IPv6、WebRTC、UDP/QUIC、虚拟网卡、系统代理和网络组件状态。不同模式下明确显示不可用或未验证的检查 |
| 实时连接 | 表格列为「时间」「程序」「网站」「线路」「流量」。可在「AI 网站」「全部」之间切换并搜索。已结束记录为灰色，保留最近 1 小时。第三方程序如 Codex 保留原名称。旧名 `AI Network Helper` 显示为「Leyra 后台组件」，搜索兼容新旧名 |
| 日志 | 显示连接、切换、异常、拦截与恢复事件，时间条保留同一时段的拦截历史。敏感字段在界面和导出中做遮蔽 |

内部探测有认证入站标识，在连接追踪、绕行告警和 VLESS 流量统计中排除。真实直连或绕行仍应可见并触发保护。UI 显示进程别名，规则继续使用真实进程名。

## 设置与授权

- 软件设置包括启动行为、后台运行和出口时区同步等。启用同步后匹配已核验出口的时区。断开时恢复由 Leyra 改动的时区，并尊重用户的独立调整。
- 注册与登录使用邮箱和密码，注册后验证邮箱，页面没有邀请码。验证完成后由服务端启动 1 天试用。
- 试用到期暂停 Claude 的受管流量，普通网页继续可用。客户端内置续购说明，永久授权 **199 元**，QQ群 **1136427075** 联系客服。永久授权开通后重新核验再恢复。
- 官网的支持范围仍以平台通过实测并发布为准。Mac 1.1.8 的版本入口和下载已发布。Windows 发布由真机结果决定。
