八项检测是什么、异常怎么处理

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

连接后,客户端会持续检查八项防护。前四项是核心防护,其中任何一项异常,AI 流量都会被暂停,直到恢复正常。这样可以保证 AI 网站不会看到你的真实网络。其他网站不受影响。

遇到异常,先点首页的「一键修复」。客户端会重新设置网络组件和 DNS,再把所有项目重新检测一遍。大部分问题这样就能解决。

独享 · 静态 ISP 代理 IP(核心)

查什么:AI 流量的出口是不是你的独享 · 静态 ISP 代理 IP。

异常的常见原因:

  • 你的节点订阅到期或流量用完,连不到独享 · 静态 ISP 代理 IP。到「节点」页点「刷新订阅」,看节点是否正常。
  • 当前节点不稳定。在「节点」页点「全部测速」,换一个延迟低的节点,或选「自动选最快」。
  • 独享 · 静态 ISP 代理 IP 暂时不可用。这种情况客户端会暂停 AI 流量,不会改走其他线路。如果持续异常,请联系客服。

DNS 防泄露(核心)

查什么:你访问网站时查询域名的请求,有没有被发给本地运营商。

异常的常见原因:其他软件(VPN、安全软件、网卡驱动)把网卡的 DNS 改回去了。客户端会自动重新设置,一般几十秒内恢复。如果反复异常,请检查是否有其他 VPN 或网络加速软件同时开着。

IPv6 防泄露(核心)

查什么:网页能不能通过 IPv6 看到你的真实地址。

异常的常见原因:你的宽带有公网 IPv6,并且在本地代理模式下无法完全接管。切换到虚拟网卡模式即可(退出 Clash 等代理软件后重新连接)。

WebRTC 防泄露(核心)

查什么:浏览器的 WebRTC 功能(用于视频通话)会不会把你的真实 IP 暴露给网页。

显示「提醒」:本地代理模式下这一项无法完全接管,只提醒、不暂停 AI。切换到虚拟网卡模式即可。

断网保护

查什么:网络组件意外退出时,AI 流量会不会被先暂停,而不是直接从你的真实网络出去。

异常的常见原因:虚拟网卡没有正常工作。点「一键修复」,或断开后重新连接。

代理冲突

查什么:电脑上有没有同时运行 Clash、Clash Verge 等其他代理软件。

显示「提醒」或「异常」:说明检测到其他代理软件,浏览器等程序的流量可能先经过它,不走独享 · 静态 ISP 代理 IP。请完全退出它(托盘图标右键「退出」),然后在 Leyra 里断开再连接。

Claude Code 线路

查什么:电脑上的 Claude Code(写代码用的命令行工具)有没有走独享 · 静态 ISP 代理 IP。它不经过浏览器,容易被忽略。

显示「提醒」:Claude Code 的代理设置指向了别的软件(比如 Clash),或指向了一个已经没有程序在用的端口。点「一键修正」,客户端会把 Claude Code 的代理改到 Leyra 的端口,原来的设置会备份,随时可以点「撤销修正」改回去。

如果你不用 Claude Code,可以忽略这一项。

Claude 看到的 IP

查什么:直接问 Claude 看到的是哪个 IP,核对是不是你的独享 · 静态 ISP 代理 IP。这是对最终结果的检查。

显示「暂时没读到」:网站一时没响应,不代表出口有问题,下次检测会再核对。

显示「异常」:Claude 看到的不是你的独享 · 静态 ISP 代理 IP。虚拟网卡模式下客户端会立刻暂停 AI 流量。请检查是否开着其他 VPN 或代理软件,然后点「一键修复」。

还是解决不了

到「网络」页点「网络诊断」,诊断完成后点「复制报告」,把报告发给客服。报告里不包含你的密码和订阅链接。
