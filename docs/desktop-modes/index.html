虚拟网卡模式和本地代理模式

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

客户端连接时会自动选择接管方式,你可以在「网络」页的「接管方式」里看到现在用的是哪一种。

虚拟网卡模式(推荐)

客户端在电脑上建一块虚拟网卡,电脑上所有程序的网络流量都会经过它。AI 网站的流量从你的独享 · 静态 ISP 代理 IP 出去,其他海外网站走你的节点,国内网站直连。

这种模式的好处是:

  • 浏览器、桌面 App、命令行工具都能管住,不需要每个程序单独设置代理。
  • DNS、IPv6、WebRTC 这些容易泄露真实网络的地方都能接管。
  • 网络组件意外退出时,会先暂停 AI 流量再自动重连,不会让 AI 网站看到你的真实 IP。

本地代理模式

电脑上同时开着 Clash、Clash Verge 等代理软件,并且它们也开了虚拟网卡(TUN)时,两块虚拟网卡会互相冲突。这时客户端会自动改用本地代理模式,只提供一个本地代理端口,不接管整台电脑。

在这种模式下:

  • 浏览器通常会跟着 Clash 设置的系统代理走,也就是走 Clash,而不是你的独享 · 静态 ISP 代理 IP。
  • Claude Code 这类命令行工具只认自己的代理设置,需要单独处理(见《哪些流量能管住》)。
  • WebRTC、IPv6 等防护无法完整生效,首页对应项会显示黄色「提醒」。

怎么切换到虚拟网卡模式

  1. 完全退出 Clash 等代理软件:在它的托盘图标上右键点「退出」,而不是只关窗口。
  2. 在 Leyra 首页点「断开连接」,再点「连接」。
  3. 到「网络」页确认「接管方式」显示为虚拟网卡模式。

Leyra 已经通过你的节点订阅处理其他海外网站,所以退出 Clash 后,海外网站依然可以正常访问。

为什么有时候是本地代理模式

除了开着别的代理软件,下面这种情况也会使用本地代理模式:

  • 客户端没有以管理员权限运行。建虚拟网卡需要管理员权限,正常安装的客户端会自动获得。如果你的 Windows 账户不是管理员,请联系电脑管理员,或右键客户端图标选择「以管理员身份运行」。
