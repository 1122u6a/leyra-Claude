虚拟网卡模式和本地代理模式

客户端有两种接管方式。虚拟网卡模式能管住电脑上所有程序;开着 Clash 等代理软件时会退到本地代理模式,防护会打折扣。

哪些流量能管住,哪些管不住

虚拟网卡模式下浏览器、AI 桌面 App、Claude Code 等命令行工具都会走独享 · 静态 ISP 代理 IP;浏览器代理插件和浏览器自带 VPN 会绕开它,用 AI 时请关掉。

安全软件弹窗和拦截怎么办
