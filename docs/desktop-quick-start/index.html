快速上手:安装、登录、连接

当前 Leyra 发行包仅支持 Apple 芯片 Mac。本页中的 Windows、手机和第三方客户端操作为原站参考资料。

更新于 2026-10-29

Leyra 桌面客户端让你电脑上的 AI 流量(Claude、ChatGPT、Gemini 的网页、桌面 App 和命令行工具)固定从你的独享 · 静态 ISP 代理 IP 出去,其他网站照常使用。这篇讲第一次使用要做的几件事。

使用前要准备什么

  • 一台 Windows 10 或 Windows 11 电脑。
  • 一个可用的节点订阅(也就是你平时用的机场订阅链接)。客户端会经你的节点连到独享 · 静态 ISP 代理 IP,其他海外网站也走你的节点,国内网站直连。
  • Leyra 账号,并已开通会员。没有账号可以在客户端里直接注册。

第一步:安装

  1. 安装前先退出 Claude:关掉 Claude 桌面版、浏览器里的 Claude 页面,以及正在运行的 Claude Code。这样连上以后 Claude 的所有连接都会走独享 · 静态 ISP 代理 IP。
  2. 从官网下载安装包,双击运行,按提示安装。
  3. 安装过程中如果 360、腾讯电脑管家、火绒等安全软件弹窗,请选择「允许」。原因和每个弹窗该点什么,见《安全软件弹窗和拦截怎么办》。
  4. 安装完成后客户端会自动打开。

第二步:登录并开通

  1. 用邮箱或 Google 账号登录(没有账号就先注册)。
  2. 还没开通会员的话,首页会先帮你做一次网络体检,告诉你现在的网络有哪些问题,再引导你开通。
  3. 开通后,系统会为你分配一个独享 · 静态 ISP 代理 IP。

第三步:填写你的节点订阅

打开左侧「节点」页,添加你的节点服务商,把订阅链接粘贴进去。添加成功后,节点列表会显示订阅里的全部节点。

默认是「自动选最快」,不需要手动选。如果想固定用某个节点,点一下它就行。

第四步:连接

回到首页,点「连接」。十几秒内会显示「已连接」,同时首页顶部会显示 Claude「可安全访问」。这时再打开 Claude。

连接后,客户端会先检查独享 · 静态 ISP 代理 IP 和各项防护,全部通过才放行 AI 流量。检查没通过时,Claude 会暂时打不开,其他网站不受影响(ChatGPT、Gemini 照常走独享 · 静态 ISP 代理 IP,不会被暂停)。这是为了保证 AI 网站看到的永远是你的独享 · 静态 ISP 代理 IP。

以后客户端更新时也一样:点「立即重启安装」之前先退出 Claude。安装更新时客户端会断开一两分钟,这段时间里开着的 Claude 会走你原来的网络。如果 Claude 开着,客户端会先提醒你。

首页底部八项检测

连接后首页底部会显示八项检测,每项的状态含义是:

  • 开启:这项防护正常工作。
  • 检测中:正在检测,稍等几秒。
  • 提醒(黄色):不影响使用,但建议处理,鼠标放上去可以看原因。
  • 异常(红色):这项防护没生效。如果是核心防护,AI 流量会被暂停,首页会出现「一键修复」按钮。

每一项具体查什么、异常时怎么处理,见《八项检测是什么、异常怎么处理》。

常用设置

左侧「软件设置」里可以调整:

  • 开机启动:登录 Windows 后自动在后台运行。
  • 启动后自动连接:打开客户端后自动连接。开机启动和这一项都打开,开机后什么都不用点就能用。
  • 关闭窗口时保留后台运行:点窗口右上角的关闭,客户端收进右下角托盘继续工作。要完全退出,在托盘图标上右键点「退出」。
  • 自动检查更新:有新版本时自动下载,重启客户端时安装。也可以点左下角版本号旁边的小图标手动检查。
