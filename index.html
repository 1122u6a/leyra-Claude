常见问题

我需要准备什么？

一台 Windows 10 / 11 或 Mac（macOS 12 及以上）电脑、一条节点订阅链接（推荐，从节点服务商后台复制；复制不出来的，用你正在用的 Clash Verge、v2rayN 等也行），再加一个你自己的独享 · 静态 ISP 代理 IP（还没有的话，文档库里有怎么买的教程）。第一次安装、登录时要先开着你的节点工具，否则客户端连不上。

独享 IP 和普通节点有什么区别？

普通节点的 IP 是很多人一起用的，而且会随节点切换变来变去。独享 · 静态 ISP 代理 IP 只给你一个人用，一直不变，Claude 每次看到的都是同一个你。Leyra 不卖 IP，用你自己买的独享 IP。

会影响我上其他网站吗？

不会。客户端只管 Claude，其他网站照常走你原来的网络。

Claude Code 也会走我的 IP 吗？

会。客户端用虚拟网卡接管整台电脑，Claude 网页版、桌面端和 Claude Code 都走你的同一个独享 IP，不用单独设置代理。

手机能用吗？

开通终身 VIP 后支持。在电脑客户端里点「添加手机」，iPhone 用小火箭扫码，安卓用 Clash Meta，手机也走你自己的独享 IP。一个账号最多 5 台设备，电脑和手机都算；试用期只支持 1 台电脑。

能和 Clash 等代理软件一起开吗？

能，但不推荐。开着别的代理软件时，客户端会改用本地代理模式，浏览器多半走的是那个软件，防护会打折扣。用 Claude 时建议先退出它。

安装时安全软件弹窗怎么办？

选「允许」。客户端要创建虚拟网卡、修改网卡的 DNS，安全软件会提示。每个弹窗该点什么，文档库里有详细说明。

支持 Mac 吗？手机呢？

支持。Mac 版和 Windows 版同时上线，Apple 芯片（M1–M4）和 Intel 都支持，需要 macOS 12 及以上；第一次打开时按提示到「系统设置 → 隐私与安全性」点「仍要打开」。iPhone 和安卓在电脑客户端里点「添加手机」扫码就行。终身 VIP 一份，电脑和手机最多 5 台。

怎么卸载？

Windows：在「设置 → 应用」里卸载 Leyra，卸载时会把网卡设置恢复原样。Mac：退出客户端，把 App 拖进废纸篓就行，后台组件会在半小时内自动清理。
